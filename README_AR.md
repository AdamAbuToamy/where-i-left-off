## الفكرة

الرابط المحفوظ وحده لا يوضح أين توقفت. البطاقة تجمع الرابط ونقطة التوقف والخطوة التالية؛ مثل واجب جامعي: «أنهيت السؤالين الأول والثاني، والخطوة القادمة حل السؤال الثالث».

## ما الموجود؟

- بطاقات وروابط وأقسام وقوائم ومواعيد متابعة وعرض أسبوعي.
- بحث وفلاتر حسب الحالة والموعد، وترتيب البطاقات باللمس والفأرة ولوحة المفاتيح.
- مساحة شخصية خاصة ومجموعات مشتركة مع دعوات وتوزيع مهام وصلاحيات للأعضاء.
- حفظ التعديلات على الجهاز دون اتصال، ثم مزامنتها عند فتح التطبيق online.
- اختيار النسخة المحلية أو السحابية عند تعارض تعديلين.
- تسجيل الدخول بالبريد وكلمة المرور أو Google.
- تطبيق ويب قابل للإضافة للشاشة الرئيسية، وإضافة Chromium لالتقاط الروابط والفيديوهات وصفحات Moodle المعروفة بعد المعاينة.
- جامعة: كورسات وملاحظات وخطة مذاكرة ووظائف وامتحانات وخريطة متطلبات وجدول أسبوعي بالأيام والساعات والقاعات.
- «اليوم في الجامعة» داخل «أكمل الآن» لعرض المحاضرات والتسليمات والمتأخرات.
- مساعد عائم للتلخيص والنصائح وملفات TXT واقتراح تعديل البطاقات والكورسات والمهام والجدول، ثم تطبيق المقترح بعد مراجعته.

هذه نسخة تجريبية. تثبيت الهاتف وقائمة المشاركة الأصلية وGoogle OAuth يحتاجون توثيق فحص على أجهزة فعلية؛ اختبارات المتصفح ليست بديلًا عن ذلك.

## الجامعة والجدول الأسبوعي

تتوفر صفحة الجامعة للحسابات ذات البريد الموثّق. أضف الكورسات والمواضيع والمهام والوظائف والامتحانات، واربط المتطلبات في خريطة قابلة للتعديل. ابنِ جدول الأسبوع بالمحاضرات والترغوليم والمختبرات، مع الأيام وساعة البداية والنهاية والقاعة.

تُزامن سجلات الجامعة عبر Firestore بصلاحيات خاصة بالحساب، مع حفظ محلي وطابور تعديلات أثناء الانقطاع ومعالجة واضحة للتعارض. الصق صفوف Excel مع معاينة وكشف التكرار وتداخل المواعيد، أو صدّر واستعد JSON للنسخ الاحتياطي. تذكيرات الهاتف تحتاج موافقة منفصلة.

الإضافة الحالية تتعرف على صفحات Moodle المدعومة التي يفتحها المستخدم ويختار استيرادها، مع معاينة الكورس أو المهمة قبل الحفظ. لا يوجد ربط دائم بحساب Moodle أو جلب تلقائي للمهام في الخلفية. [دليل الجامعة](docs/UNIVERSITY_PILOT_AR.md) · [دليل الإضافة](browser-extension/README_AR.md).

## مساعد AI

افتح المساعد العائم داخل الموقع، واسأله عن بياناتك المحفوظة أو اطلب تلخيصًا ونصائح وملفًا نصيًا، أو اقترح تعديل بطاقة أو كورس أو مهمة أو علاقة متطلبات أو حصة في الجدول. يعرض المقترح أولًا؛ بعد الضغط على **تطبيق التغييرات** يُحفظ بنفس صلاحيات المستخدم، مع فحص التعارض وتأكيد النتيجة من الخادم. التراجع المدعوم لا يكتب فوق تعديل أحدث. المهام المرتبطة بتذكير هاتف تُعدّل من صفحة الجامعة للمحافظة على اتساق جدولة الإشعارات.

- **سحابي:** GPT-OSS-120B عبر Cloudflare Worker الموجود. الإعداد بـ`node scripts/setup-free-assistant.mjs`. تطبق حصة المزود المجانية وفاصل قصير ضد الإغراق؛ أُلغي حد التطبيق القديم من عشر محاولات يوميًا.
- **محلي اختياري:** اختر «تشغيل Qwen على جهازي» داخل الشات. يعمل Qwen2.5 1.5B عبر WebLLM في Worker بعد تنزيل أولي كبير يقارب 1GB. يحتاج WebGPU وذاكرة GPU مناسبة؛ يذكر إعداد النموذج نحو 1.6GB. لا توجد حصة رسائل من مزود AI في هذا الوضع، لكن السرعة والجودة وسعة السياق تعتمد على الجهاز. يبقى الاتصال بـFirebase مطلوبًا للمزامنة وحفظ التعديلات. فشل المحلي لا يحوّل الرسالة للسحابة تلقائيًا.
- **قوائم الجدول المنظمة:** القائمة المستقلة تستخدم محللًا مع مطابقة الكورسات السحابية. تعديلات البطاقات والكورسات الحرة والطلبات المركبة تذهب إلى النموذج السحابي.

الواجهة والردود تدعم العربية والإنجليزية والعبرية. يوجد انتظار متحرك يوضح قراءة البيانات وتجهيز الرد والحفظ، وتقدم فعلي لتنزيل النموذج، مع دعم تقليل الحركة. يتعامل المساعد مع النص المحفوظ في الموقع، ولا يفتح محتوى الروابط أو ينفّذ كودًا مولّدًا. [نتائج اختبار مهام المساعد وحدودها](docs/AI_ACCEPTANCE_AR.md) · [الخصوصية](https://where-i-left-off.web.app/privacy.html). لم يُختبر استدلال GPU الفعلي في بيئة التطوير؛ نجاح مسار الحفظ واختبارات الردود المحقونة لا يعني نجاح كل طلب لغوي أو ضمان سرعة موحدة.

## التجربة والتثبيت

افتح [الموقع](https://where-i-left-off.web.app/)، سجّل الدخول وأضف أول بطاقة. سجّل الدخول online أولًا قبل الاعتماد على العمل دون اتصال. المزامنة تعمل عند فتح التطبيق مع الاتصال؛ لا نعد بمزامنة وهو مغلق.

[طريقة التثبيت على Android وiPhone](docs/INSTALL.md) · [إضافة حفظ التبويب للكمبيوتر](browser-extension/README_AR.md)

## التشغيل للمطورين

المتطلبات: Node.js 24 وnpm وJava 21 لاختبارات المحاكيات.

```bash
npm ci --include=dev
cp .env.example .env.local
# ضع إعدادات Firebase web الخاصة بمشروعك داخل .env.local.
npm run dev
```

لتجربة محلية باستخدام المحاكيات، شغّل في نافذتين:

```bash
npm run emulators
npm run dev:emulator
```

## التحقق

```bash
npx playwright install --with-deps chromium
npm ci --prefix push-worker
npm test --prefix push-worker
npm audit --omit=dev --audit-level=high
npm run test:all
```

اجتاز آخر تحقق محلي **252 اختبار وحدة ومكونات، و56 اختبار Firestore وأمان وقبول لواجهة الشات، و35 اختبار Worker**، إضافة إلى البناء وفحص الكود. اختبار القبول يضغط زر التطبيق الفعلي ويقرأ نتيجة الحفظ من محاكي Firestore؛ اختبارات محول النموذج تستخدم ردودًا محقونة. [تفاصيل المساعد](docs/AI_ACCEPTANCE_AR.md). ملف TEST_RESULTS.md يحتفظ بنتائج تاريخية أقدم؛ نتائج المتصفح وفحص التبعيات الحالية تظهر في [GitHub Actions](https://github.com/AdamAbuToamy/where-i-left-off/actions).

[تفاصيل النتائج وحدودها](TEST_RESULTS.md) · [نطاق الأمان](SECURITY.md) · [خطة التطوير](ROADMAP_AR.md)

لا تشغّل اختبار المتصفح وبناء الإنتاج بالتوازي؛ كلاهما يكتب إلى dist. سكربت النشر الموجود مخصص لمشروع Firebase الخاص بالمطور؛ من ينسخ المشروع يستخدم إعداداته وأهداف الاستضافة الخاصة به.

المساعد وصفحة الجامعة والتذكيرات الاختيارية موجودة كما هو موضح أعلاه. متابعة الردود الخارجية ورفع الملفات الثنائية والربط الدائم بمنصة Moodle غير متاحة حاليًا. إلغاء الوصول السحابي لا يمحو نسخًا نُزّلت سابقًا على جهاز غير متصل.

## إشعارات التطبيق المثبّت

تذكيرات Web Push اختيارية عبر Cloudflare Workers Free وD1 وQueues، مع بقاء Firebase على Spark. إعداد النشر هذا لا يتطلب Blaze أو بطاقة دفع، لكن الحصص المجانية محدودة وقد تتوقف الخدمة عند نفادها. جهّز Worker المنفصل قبل نشر الواجهة. [الإعداد وفحص الهاتف](docs/PUSH_NOTIFICATIONS_AR.md).


### تغطية تنفيذ المساعد

يمكن أن يتضمن الرد حتى 50 عملية بيانات و20 إجراء موقع بعد المراجعة: البطاقات وترتيبها وأرشفتها واستعادتها، الأقسام والكورسات والمهام والحصص، المظهر واللغة والسكون وإعدادات التنظيم، وفتح العروض والتصفية. سجل المهام يبيّن نتيجة كل مهمة بحسب الحفظ المؤكد، ولا تُعد رسالة بلا تعديلات تنفيذًا ناجحًا. قائمة الجدول العربية/العبرية ذات الحصص الـ14 لها مسار مباشر يتحقق من الأسماء والمواعيد ويمنع التكرار.

الأذونات وعمليات الحساب والأمان وعضوية المجموعات تستخدم واجهتها الأصلية مع توضيح الخطوة المطلوبة. إعدادات الجهاز منفصلة عن معاملة حفظ البيانات. لا يوجد ضمان لفهم كل صياغة ممكنة. انظر [العمليات والحدود ونتائج الفحص](docs/ASSISTANT_CAPABILITIES_AR.md).

اختلاف اسم الكورس في قائمة الجدول يذهب الآن إلى النموذج السحابي للمطابقة بالمعنى بدل اشتراط الاسم الحرفي. لا تُقبل إلا معرّفات كورسات موجودة، وتبقى الساعات والأنواع تحت فحص التطبيق. المساعد السحابي لا يتطلب تنزيل نموذج محلي.

في مسار Cloudflare السابق يُحصي المساعد الطلبات باستدعاء مستقل قبل توليد العمليات. أما مسار Groq الحالي فيختار العمليات والمعاملات باستدعاء أدوات واحد، ويتحقق الكود من المخطط وفهارس الطلبات ثم مخطط العميل من صلاحية التنفيذ. إنشاء بطاقة وتحديد موعدها وإضافة ملاحظة ثلاثة طلبات، ولو نفذتها كتابة واحدة. توجد محاولة تصحيح دلالي واحدة؛ المقترح الناقص يُرفض. الملاحظات الشخصية تُحفظ في حقل الوصف الموجود وأصبح قابلاً للتحرير. مراجعة جميع وظائف الواجهة وحدود التنفيذ في [جدول الإمكانيات](docs/ASSISTANT_UI_AUDIT_AR.md).

حصة Cloudflare المجانية 10,000 neuron يوميًا للحساب كله، وليست رسائل غير محدودة لكل مستخدم. مسار Cloudflare لا يحتاج تنزيلًا أو مفتاح API خارجيًا؛ بديل Groq يحتاج مفتاحًا واحدًا لصاحب الموقع على الخادم. لا يوجد انتقال تلقائي بين المزودين. [النموذج الرسمي](https://developers.cloudflare.com/workers-ai/models/gpt-oss-120b/) · [الحصة والأسعار](https://developers.cloudflare.com/workers-ai/platform/pricing/).

[تحليل فشل المساعد ومجموعة 618 طلبًا وحدود نتائجها](docs/ASSISTANT_FAILURE_ANALYSIS_AR.md). تشغيل الاختبار الحي: `npm run test:assistant:live -- --limit=618 --resume`؛ اختبارات الردود المحقونة لا تثبت فهم النموذج.


بديل سحابي بحصة مختلفة: [ربط Groq وحدوده الفعلية](docs/GROQ_ASSISTANT_AR.md). يحتاج مفتاحًا واحدًا لصاحب الموقع على الخادم، ولا يحتاج المستخدمون مفاتيح أو تنزيلات. اختبر ثلاث رسائل قبل النشر.

مسار Groq الحالي يستخدم استدعاء أدوات واحدًا لاختيار عمليات الموقع ومعاملاتها، مع التحقق بالكود ثم مخطط العميل والصلاحيات والحفظ المؤكد. لا يستخدم حصرًا لغويًا باستدعاء مستقل. مسار Cloudflare السابق بقي كما هو. توافق 618 حالة مكتوبة مسبقًا لا يثبت استدلال النموذج الحي.

أُعيد بناء اتصال المساعد بمراحل أخطاء واضحة وفحص اتصال محمي دون استهلاك AI، وتحقق إصدار Worker وCORS قبل نشر الواجهة، ومسار نموذج واحد لكل رسائل الشات. [مراجعة إعادة البناء ومصادرها وحدود التحقق](docs/ASSISTANT_REBUILD_AR.md).
