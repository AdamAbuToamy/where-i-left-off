# إضافة Where I Left Off لمتصفح Chrome

الإضافة تحفظ **عنوان التبويب الحالي ورابطه فقط بعد ضغطك على الأيقونة**. لا تقرأ نص الصفحة أو بقية التبويبات. بعد الضغط تفتح الموقع بنموذج إضافة جاهز؛ سجّل الدخول إذا طُلب منك، عدّل الاسم، ثم أضف الخطوة التالية واحفظ البطاقة.

## تجربة الإضافة محليًا

1. افتح `chrome://extensions` في Chrome على الكمبيوتر.
2. فعّل **Developer mode**.
3. اختر **Load unpacked** وحدد هذا المجلد `browser-extension`.
4. ثبّت الإضافة بجانب شريط العنوان.
5. افتح صفحة تريد تذكرها واضغط أيقونة الإضافة.

الإضافة مهيأة لفتح الموقع المنشور على `https://where-i-left-off.web.app/`. يجب نشر تحديث الموقع الذي يدعم رابط `?capture=tab` حتى يعمل ملء النموذج تلقائيًا.

الصفحات الداخلية المحمية للمتصفح مثل `chrome://` لا يمكن حفظها بهذه الطريقة. إذا لم يكن للصفحة عنوان، لن تفتح الإضافة نموذجًا فارغًا.

## الهاتف

هذه إضافة Chrome للكمبيوتر. على Android ثبت الموقع من قائمة Chrome باختيار **Install app / تثبيت التطبيق**، ثم افتح الصفحة المطلوبة واختر **مشاركة** واختر Where I Left Off. سيظهر نموذج بطاقة يحتوي الرابط. قد يتطلب ظهور هدف المشاركة إعادة تثبيت التطبيق بعد تحديث الموقع.

## الإصدار 0.2.0: حفظ موضع الفيديو

تحتاج Reload بعد التحديث. عند الضغط فقط، تقرأ الإضافة الوقت الحالي للفيديو إن كان متاحًا، وتفتح التطبيق للحفظ التلقائي في الحساب المسجل. تضيف رابطًا زمنيًا لـ YouTube وتحدّث البطاقة الموجودة للرابط نفسه. للمشغلات الأخرى الوقت محفوظ في نقطة التوقف؛ القفز التلقائي إليه غير مضمون. مشغلات الإطارات الخارجية والصفحات المقيدة قد تحفظ العنوان والرابط فقط. لا قراءة لبيانات الفيديو المشفر أو ملفات المستخدم ولا تتبع دائم في الخلفية. التفاصيل في UPDATE_WORKFLOW_AR.md.

## الإصدار 0.3.0: التقاط جامعي اختياري
عند الضغط على الإضافة داخل صفحة كورس أو وظيفة أو اختبار في Moodle، تقرأ العنوان والرابط واسم الكورس من الصفحة المفتوحة فقط، ثم تفتح معاينة في «الجامعة». اختر كورسًا موجودًا أو وافق على إنشاء كورس ثم أكّد الإضافة. لا تُنشأ بطاقة عادية تلقائيًا في هذا المسار. العنصر المحفوظ للرابط نفسه يُفتح للتعديل دون تكرار. موعد التسليم لا يُخمن؛ أدخله بعد مراجعته. لا تُقرأ كلمات المرور أو الكوكيز ولا تستخدم واجهة Moodle أو المزامنة الخلفية. قد لا تُعرف بعض القوالب المعدلة أو الصفحات التي تخفي رابط الكورس؛ عندها يبقى حفظ الصفحة العادي. تدعم الإضافة Chrome على الكمبيوتر؛ لا تتوافر في Chrome على Android.

للتحديث اليدوي: chrome://extensions ← Developer mode ← Load unpacked ← اختر مجلد browser-extension من المشروع، أو Reload إن كان محملًا. النسخة الموجودة في المتجر تحتاج رفع حزمة الإصدار الجديد ومراجعته؛ نشر الموقع وحده لا يحدث الإضافة.

## تحديث 0.4.0 داخل الإضافة الحالية
يجب رفع wilo-extension-0.4.0.zip داخل العنصر الموجود أصلًا في Chrome Web Store، بالمعرّف المثبت في public/extension-config.json، وعدم إنشاء عنصر جديد. سيصل الإصدار لمستخدمي الإضافة الحالية بعد اعتماد ونشر التحديث وفق آلية المتجر. لا يغير السكربت إعدادات الجمهور أو الدول في حساب الناشر. اختر Public والدول المطلوبة من لوحة الناشر إن كانت النسخة محدودة سابقًا.

المصدر يدعم صفحات Moodle المطابقة من أي جامعة دون قائمة دومينات، ويقرأ وصفًا وتواريخ وروابط مواد وأسماء محاضرين ظاهرة ضمن حدود الحزمة. التواريخ المؤكدة تملأ حقل التسليم للمراجعة، والمبهمة تبقى نصًا. زر مراجعة تحديث من الصفحة يسمح باستيراد تاريخ جديد لمهمة محفوظة بعد موافقتك، مع إبقاء الملاحظات والإنجاز. لا تُقرأ كلمات مرور أو كوكيز أو صفحات غير مفتوحة. لا يُضاف أي إذن جديد. الموقع متاح لكل مستخدم ببريد موثق، وليس مقيدًا بحساب المطور.
