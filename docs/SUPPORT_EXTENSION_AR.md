# تحديث الدعم والخصوصية واقتراح الإضافة

## ما أضيف
- اقتراح إضافة Chrome على الكمبيوتر عند توفر رابط متجر منشور، دون نافذة تعطل الاستخدام.
- «ذكّرني بعد 7 أيام»، «لا تعرض مجددًا»، «ثبّت الإضافة بالفعل».
- قسم دائم في الإعدادات: رابط المتجر، التحقق مجددًا، إعادة إظهار الاقتراحات.
- دعم العربية والعبرية والإنجليزية، مع الإبقاء على تصميم الموقع.
- نموذج Feedback خاص: اقتراح، مشكلة، طلب خصوصية، مساعدة في حذف الحساب؛ سجل وردود داخل الموقع.
- صندوق الإدارة في `#/admin/support`؛ الردود للمدير الموثق فقط.
- منع انتحال المستخدم وفرض دقيقة بين الطلبات من قواعد الخادم، لا من الواجهة وحدها.
- صفحات عامة `/privacy.html` و`/terms.html` و`/support.html`، وروابطها عند الدخول وفي الإعدادات وأسفل الموقع.
- تحديث وسيلة التواصل في سياسة الإضافة لتشير إلى الدعم الخاص، بدل GitHub.
- تصدير JSON للبطاقات والأقسام وتفضيلات سير العمل والجلسات الشخصية. لا يتضمن محتوى المجموعات أو التشخيص أو كل سجلات الحساب؛ الطلبات الإضافية عبر الدعم.
- مسار طلب مساعدة واضح حين تتعذر خدمة الحذف، دون تجاوز التحقق الأمني أو الادعاء بإتمام الحذف.
- تنظيف طلبات Feedback عند حذف الحساب، وتحسين تنظيف نسخ الحساب المحلية.
- تحديث النشر ليتضمن الفهارس المطلوبة وفرض إعدادات الإنتاج.

## تفعيل رابط المتجر لاحقًا
الملف `public/extension-config.json` يبدأ بمعرّف فارغ و`published: false`؛ لذلك لا يظهر اقتراح تثبيت مبكر أو رابط وهمي.
انسخ معرّف الإضافة الحقيقي (32 حرفًا من a إلى p) من لوحة Chrome Web Store.
يمكن حفظه أثناء انتظار المراجعة دون عرض رابط التثبيت:

```bash
node scripts/configure-extension.mjs YOUR_EXTENSION_ID
```

بعد موافقة المتجر وتأكد فتح رابطها للعامة:

```bash
node scripts/configure-extension.mjs YOUR_EXTENSION_ID --published
VITE_TEST_OFFLINE=false bash scripts/deploy-production.sh
```

استبدل YOUR_EXTENSION_ID بالقيمة الحقيقية. لا يوجد معرّف مفترض داخل هذا التحديث.

## اكتشاف التثبيت
النسخة المقدمة سابقًا للمتجر 0.2.1 لا تؤكد وجودها للموقع. أعددنا نسخة 0.2.2 لتحديث لاحق، بنفس معرّف المتجر عند رفعها كتحديث للعنصر نفسه.
تقبل رسالة وجود فقط من `https://where-i-left-off.web.app/`، وترد بالوجود والإصدار دون قراءة الصفحة.
عدم وصول رد لا يثبت عدم التثبيت؛ لذلك يوجد خيار «ثبّت الإضافة بالفعل» وشرح لعدم دعم النسخ القديمة.
لا تلغِ المراجعة الحالية لمجرد هذا التحديث. بعد انتهائها ارفع ملف `extension-0.2.2-next-release.zip` كتحديث للعنصر الحالي عند استعدادك.
لا تظهر الاقتراحات على الهاتف أو Firefox. الدليل اليدوي والتأجيل محليان لهذا المتصفح ويمكن إعادة ضبطهما من الإعدادات.

## نشر الموقع
احتفظ بملف `.env` الحالي؛ حزمة التحديث لا تحتوي بيانات اعتماد ولا تغير إعداداتك المحلية.

```bash
npm run lint
npm test
npm run test:rules
npm run test:e2e
VITE_TEST_OFFLINE=false bash scripts/deploy-production.sh
```

يحتاج المحاكي إلى Java 21، واختبار المتصفح إلى Chromium مثبت عبر Playwright. تأكد من نجاح CI قبل النشر. النشر يشمل Hosting والقواعد والفهارس. قد تحتاج الفهارس بعض الوقت لتصبح جاهزة؛ تعرض الواجهة خطأ وإعادة محاولة بدل إخفاء فشل تحميل الطلبات.

## تشغيل خدمة حذف الحساب الموجودة
لا يفعّل هذا التحديث خدمة الحذف تلقائيًا، ولا ينشئ مفاتيح أو يضعها في Git.
من Settings → Secrets and variables → Actions في المستودع:
- Secret باسم `FIREBASE_SERVICE_ACCOUNT` لبيانات اعتماد مخصصة للمشروع، تحفظ كسر وليس ملفًا في المستودع. امنح العامل صلاحيات حذف حسابات Firebase Auth وبيانات Firestore المطلوبة فقط.
- Variable باسم `FIREBASE_PROJECT_ID` بقيمة `where-i-left-off-b5683`.
- Variable باسم `ACCOUNT_DELETION_ENABLED` بقيمة `true` بعد مراجعة الصلاحيات.
شغّل workflow «Account deletion worker» يدويًا، وتحقق من نجاحه؛ ثم يعمل مجدولًا كل ساعة. قد تتأخر جدولة GitHub. يسمح الموقع بطلب الحذف فقط حين يجد نبض خدمة صالحًا.
طلبات الحذف المؤكدة قابلة للاستعادة خلال 24 ساعة، ثم تعالج في التشغيل الناجح التالي. طلب المساعدة اليدوي لا يوقف الحساب أو يحذفه تلقائيًا، ولا يفعّل العامل.
راجع سجل العامل والطلبات بنفسك دوريًا. لا وعد بتنظيف سجلات الخادم بعد مدة ثابتة ما لم توجد آلية تشغيل فعلية لذلك.

## متابعة Feedback
افتح `#/admin/support` بحساب المدير الموثق. تظهر أحدث 100 رسالة، ويمكن الرد وتغيير الحالة. يرى المستخدم أحدث 30 طلبًا له فقط. لا تُرسل رسائل بريد تلقائيًا. لا تنشر رسائل المستخدمين أو تصدرها إلى GitHub.
المرسل يحتاج تسجيل دخول؛ استخدم استعادة كلمة المرور إذا فقد الدخول. الحساب الذي طلب حذفًا ما زال يستطيع فتح الدعم خلال فترة الانتظار.

## المتابعة الخارجية
- ضع رابط الخصوصية العام `https://where-i-left-off.web.app/privacy.html` في إعدادات OAuth التي تتطلبه.
- سياسة الإضافة العامة: `https://where-i-left-off.web.app/extension-privacy.html`.
- وسيلة الدعم للمتجر: `https://where-i-left-off.web.app/support.html`.
- تحقق من فتح الروابط دون تسجيل دخول بعد النشر. هذه الصفحات تصف السلوك الفعلي وليست ضمانًا للامتثال لكل قانون أو كل متطلبات المتجر المستقبلية.
