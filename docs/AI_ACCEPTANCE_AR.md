# اختبار قبول المساعد

الاختبار يستخدم واجهة الشات وزر التطبيق الحقيقيين داخل DOM مع محاكي Firestore. القياسات محلية وليست قياس استدلال GPU أو شبكة الإنتاج. لا يُستدعى نموذج للأوامر الواضحة في الجدول التالي.

| الطلب | ظهور المقترح ms | الحفظ وقراءة الخادم ms |
|---|---:|---:|
| انشئ كورس باسم Algorithms | 519 | 392 |
| اضف الكورس اللي عندي الى البرنامج يوم احد من الخمسة للستة مساء | 119 | 293 |
| أنشئ بطاقة باسم مراجعة الخوارزميات والخطوة القادمة حل تمرينين | 109 | 294 |
| عدل بطاقة مراجعة الخوارزميات الخطوة القادمة حل خمسة تمارين | 104 | 346 |

نجح 227 اختبار وحدة/مكونات، و34 Worker، و52 Firestore/قبول واجهة، والبناء وESLint.

اختبارات النموذج المحلي تختبر التحميل الصريح وعقد الاستدلال وإغلاق Worker وعدم التحويل الخفي للسحابة ورفض السياق الزائد، بردود محقونة. لا يوجد GPU متاح هنا لقياس جودة أو سرعة استدلال Qwen المحلي، ولا توجد جلسة Cloudflare لاختبار النموذج السحابي حيًا. لذلك لا نَعِد بقدرة أي نموذج على كل طلب ولا بزمن إنتاج مماثل للأرقام أعلاه.

أعيد إنتاج فشل اختلاف ترتيب المفاتيح وفشل تحديث بطاقة مجموعة قديمة قبل الإصلاح؛ كلاهما نجح بعده. بقي اختبار رفض دور غير مخول وحساب مختلف والتعارض وعدم الكتابة فوق تعديل أحدث. لم تتغير قواعد الوصول أو App Check.
