# فحص قبول المساعد — 23 أكتوبر 2026

يوجد فصل بين فحص البرنامج وفحص الاستنتاج اللغوي الحي. اختبارات الردود المحقونة لا تثبت فهم Qwen، ولا تقيس زمن استدلاله أو شبكة الإنتاج. حُذفت القياسات السابقة التي قد توحي بأن إنشاء الكورسات والبطاقات لا يحتاج نموذجًا؛ هذه الطلبات الحرة تمر الآن عبر النموذج.

| مجموعة الفحص | ما تتحقق منه |
|---|---|
| مصفوفة العمليات | تعديل كل حقل منشور للبطاقات والأقسام والكورسات والمهام والحصص، وعزل التعديل عن البيانات الأصلية |
| طلب مركّب | إنشاء «محمد» وربط حصة الأحد 00:00–01:00، بدل تخزين جملة الطلب كاسم |
| بطاقة في الأسبوع | إنشاء «عمار» بتاريخ 25 من الشهر المحلي وفتح الأسبوع الذي يحتويه |
| عشر مهام مترابطة | أسماء مؤقتة للأقسام والبطاقات والكورسات والمهام والحصص، مع إعدادات وفتح صفحة وسجل لكل عملية |
| التصحيح التلقائي | رد غير JSON، حقل غير صالح، معرّف مفقود، محاولة واحدة فقط، وحفظ الطلب والسياق كاملين |
| أخطاء لا تعاد | الصلاحيات والحساب والتعارض والتعديلات غير المتزامنة والتذكيرات المرتبطة وحصة المزود |
| منع التكرار | الحصة المطابقة تُتجاوز في منفذ عمليات البيانات حتى عند اقتراحها من النموذج |
| التواريخ والساعات | تاريخ مستحيل، موعد جامعة دون منطقة زمنية، 00:00، وقت نهاية يسبق البداية، يوم غير صالح |
| Firebase الفعلي في المحاكي | تطبيق الدفعة ذريًا، ثم قراءة جديدة، والعزل بين الحسابات والمجموعات والتعارض والتراجع |
| المتصفح | الرسالتان العربيتان، تصحيح الرد قبل المراجعة، زر التطبيق، التحقق من الجدول والبطاقة بعد تحديث الصفحة؛ رد المزود محقون |
| اللغات | عقود ar/en/he، رسائل التصحيح وأسباب رفض البيانات مترجمة، وعدم تحويل طلبات الإنشاء الحرة لأسماء بواسطة regex |

الاختبارات الآلية ليست تعدادًا لكل جملة يمكن أن يكتبها إنسان. جودة فهم النموذج الحي تحتاج تشغيله من حساب Cloudflare المنشور، وهو غير متاح ببيانات اعتماد الإنتاج في بيئة التحرير. لا تُطلب مفاتيح خاصة أو ملفات env من المستخدم في المحادثة.

لتشغيل الفحص البرمجي: `npm test`، و`npm test --prefix push-worker`، و`npm run test:rules`، و`npm run test:e2e`، و`npm run lint`، و`npm run build`.

مراجعة وظائف الواجهة وحدود التنفيذ في `docs/ASSISTANT_UI_AUDIT_AR.md`، والعقد في `docs/ASSISTANT_CAPABILITIES_AR.md`.
