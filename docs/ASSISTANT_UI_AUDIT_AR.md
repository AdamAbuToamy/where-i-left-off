# مراجعة وظائف الموقع المتاحة للمساعد

نطاق المراجعة: واجهات `src/components` و`src/university` ونماذج البيانات ومنفذا المساعد. «تنفيذ» يعني مقترحًا ثم تطبيقًا عبر منفذ الموقع وصلاحيات المستخدم، وليس إعطاء النموذج مسارًا عشوائيًا لقاعدة البيانات أو جعله ينقر أزرار DOM.

| الواجهة / الوظيفة | طريقة التنفيذ أو الإجراء المتبقي |
|---|---|
| إضافة بطاقة، تعديل الاسم والخطوة التالية والملاحظات/الوصف | `projects create/update`؛ فحص حدود النص |
| بدء/إكمال/انتظار/لاحقًا | `projects.status`؛ سلوك الإنجاز من كيان البطاقة الأصلي |
| تاريخ التسليم والمتابعة، عرض الأسبوع | `dueDate/followUpDate`؛ `navigate view:week,weekOf` |
| قائمة تحقق ونقطة توقف | `checklist/checkpoint`؛ القائمة نص بصيغة الموقع |
| نوع المورد وتقدمه وروابطه ومرفقه وصورته | `resourceType/progressUnits/totalUnits/projectUrl/attachmentUrl/links/coverUrl`؛ لا بحث تلقائي في كتالوج خارجي |
| ترتيب البطاقة وتعيين عضو ونقلها بين الأقسام | `rank/assignedTo/sectionId`؛ معرّفات حساب حقيقية وصلاحيات المجموعة |
| إضافة قسم، تسميته وحذفه | `sections`؛ نقل بطاقاته أولًا في المقترح نفسه |
| أرشفة/إلغاء الأرشفة، السلة/الاستعادة | `archivedAt/trashedAt`؛ الحذف الدائم يستخدم زر السلة الأصلي |
| البحث والتصفية والبطاقات/الأسبوع وبطاقاتي | `navigate` إلى العرض مع `search/filter/section/mine/view` |
| إضافة/تعديل/حذف كورس | `courses`؛ معالجة المهام والحصص وروابط المتطلبات قبل الحذف |
| نسخ كورس كقالب | إنشاء كورس جديد بقيمه المطلوبة ومعرّف جديد؛ لا تعديل محتوى المصدر المستورد تلقائيًا |
| ملاحظات الكورس والرابط والمواضيع وحالة إنجازها | `notes/url/topics` |
| خريطة المتطلبات وتحريك الكورسات | `requires/x/y`؛ رفض الحلقات والمرجع المفقود |
| إضافة/تعديل/حذف مهمة أو وظيفة أو امتحان وإنجازها | `tasks` مع نوع المهمة وموعد ذي منطقة زمنية؛ التذكير المرتبط يستخدم محرر الجامعة |
| إضافة/تعديل/حذف حصة أو صفوف أسبوعية متعددة | `lessons`؛ نوع اللقاء واليوم والوقت والقاعة والملاحظة؛ لا قاعة مخترعة |
| حصص متطابقة | تجاوز الإنشاء المكرر داخل منفذ العمليات؛ الحفاظ على قاعة الحصة الموجودة |
| فتح الجامعة أو كورس أو الجدول أو الخريطة | `navigate` مع `tab/courseId` |
| استيراد ملف/نسخة احتياطية أو قراءة صفحة عبر الإضافة | فتح الجامعة؛ اختيار الملف/التقاط الصفحة إجراء مستخدم؛ لا قراءة حساب Moodle غير موصول |
| تعارض مزامنة الجامعة أو إعادة المحاولة | أزرار المزامنة والاختيار الأصلية؛ لا اختيار نسخة أو كتابة فوق بيانات معلقة تلقائيًا |
| تصدير ملخص المهام PDF أو نسخة الجامعة JSON | فتح الصفحة المناسبة واستخدام زر التصدير الأصلي؛ ملف المساعد النصي لا يُسمّى PDF أو نسخة احتياطية |
| تلخيص المحتوى والنصائح وإنتاج ملفات | إجابة وملفات نصية؛ فقط المحتوى المرسل في السياق؛ لا ادعاء قراءة رابط أو ملف غائب |
| ألوان وخلفية ولغة وسكون | `appearance/language/sleep`، باستخدام التخزين والأحداث الأصلية |
| أرشفة تلقائية وتذكير ومدة مراجعة | `workflow`؛ تحديث ذري يقارن القيم ويحافظ على الخيارات الأخرى |
| إشعارات سطح المكتب | `workflow.desktop` عند وجود إذن سابق؛ إذن جديد يحتاج زر المتصفح |
| إشعارات Push وفئاتها وهدوء الليل واختبارها | فتح إعدادات الإشعارات؛ الأزرار الأصلية تدير اشتراك الجهاز وصلاحياته |
| الدليل الترحيبي | `tour` يعيد تشغيل الدليل الأصلي |
| جلسة تركيز: بدء/إيقاف/استئناف/إنهاء | واجهة التركيز الأصلية؛ لا اختلاق جلسات أو أوقات عمل. حقول البطاقة مثل التقدم ونقطة التوقف قابلة للتعديل بشكل مستقل |
| التحليلات وسجل الجلسات | فتح الصفحة؛ إحصاءات الجلسات غير المرفقة بالسياق لا يُدّعى تحليلها |
| السجل التقني وتصديره/إعادة تحميله | فتح السجل؛ لا حذف سجلات أمان أو اختلاق تصدير |
| الملف الشخصي وكلمة المرور وتصدير الحساب وحذفه | فتح الإعدادات؛ نماذج الحساب وإعادة التحقق الأصلية |
| تسجيل الدخول/الخروج والتحقق/استعادة كلمة المرور | واجهة الحساب الأصلية؛ لا وصول للمساعد إلى كلمة المرور أو الجلسة السرية |
| إنشاء/دخول/حذف مجموعة، دعوات وأدوار وأعضاء وإعلانات | واجهة المجموعات الأصلية؛ لا يُعلن إنجازها بمجرد فتح الصفحة |
| الدعم: إرسال بلاغ، سجل البلاغات والرد الإداري | فتح الدعم؛ الإرسال والرد يستخدمان نموذج المستخدم/الإدارة |
| الإدارة والحظر والأمان والنشر | أدوات الإدارة المصرح بها؛ المساعد لا يمنح نفسه دورًا أو يغيّر API/App Check/القواعد |
| روابط قانونية أو خارجية وأزرار المتصفح | الرابط/الواجهة الأصلية؛ لا ادعاء تنفيذ محتواها |
| تطبيق المقترح، إلغاؤه والتراجع عنه | تطبيق مُراجع، إيصال حفظ، وفحص تعارض عند التراجع؛ إجراءات الجهاز مستقلة عن تراجع البيانات |

لكل طلب متعدد، مطلوب سجل يبين المقترح والمعلومات الناقصة والخطوات التي تستلزم واجهتها. لا يعني مرور عقد JSON أن النموذج فهم كل نية لغوية؛ لذلك تبقى فحوص الاستنتاج الحي منفصلة عن فحوص المنفذ والمزامنة والصلاحيات.

أصبحت ملاحظات البطاقة والوصف محررًا ظاهرًا في نموذجها في اللغات الثلاث، وتستخدم الحقل الموجود `description`؛ لا يوجد دفتر ملاحظات عالمي منفصل. الطلب «أضف ملاحظة» بعد إنشاء بطاقة واحدة يرجع إليها ما لم يذكر المستخدم عنصرًا آخر. قبل عرض مقترح سحابي، يُقارَن بسجل نوايا مستقل وعدد الآثار المطلوبة وقيم حقولها، مع تصحيح واحد للإغفال. سجل النوايا استنتاج نموذجي وليس ضمانًا لكل تعبير ممكن.
