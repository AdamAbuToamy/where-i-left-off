# تفريغ جلسة العمل

افتح بطاقة ثم «جلسة عمل». تظهر ثلاثة تبويبات فقط:

- **التفريغ:** نزّل النموذج مرة واحدة، ثم اضغط دائرة الميكروفون وسجّل مقطعًا قصيرًا. اضغط زر الإيقاف لتحويل المقطع كاملًا إلى نص. الحد الظاهر 24 ثانية، ويتوقف التسجيل تلقائيًا عند بلوغه. راجع النص وصحّحه، واختر «ملاحظة» أو «خطوة قادمة» ثم «موافقة وحفظ»، أو ألغِ المقطع. كل مقطع معتمد يظهر في سطر مستقل.
- **ملاحظاتي:** اكتب ملاحظة يدويًا، ثم أضفها أو عدلها أو احذفها.
- **قائمة المهام:** أضف البنود يدويًا، وحدد المنجز منها.

الكلام يُكتب فقط، حتى إن احتوى أوامر مثل «احذف القائمة». لا يستخرج ملاحظات تلقائية ولا ينفذ أوامر. تبقى نقطة التوقف والخطوة القادمة داخل قسم قابل للفتح، وإنهاء الجلسة يحفظ سجلها المعتاد. يمكن إنهاؤها دون كتابة نقطة توقف جديدة.

## النموذج والخصوصية

النموذج المحلي هو [Whisper Large V3 Turbo](https://huggingface.co/onnx-community/whisper-large-v3-turbo)، بإصدار مثبت `360ebcde2559d60bb474678be3c1de9ef347d01a` ووزن q4f16. يُنزّل باختيارك قبل تشغيل الميكروفون، بحجم يقارب 565 ميجابايت إضافة إلى ملفات التشغيل. تحفظ الأوزان الكبيرة في مساحة الملفات الخاصة بالموقع (OPFS)، والملفات الصغيرة في المخبأ؛ يتحقق التطبيق من اكتمال حفظ الأوزان قبل إعلان الجاهزية. يعاد استخدام الملفات؛ حذف بيانات الموقع أو إخلاء المتصفح للمخبأ يستلزم التنزيل مجددًا. لا ينزل عند فتح الموقع أو تثبيت PWA.

الصوت يبقى في الجهاز ولا يرفع إلى خدمة سحابية. لا يبدأ النموذج التحليل أثناء التسجيل. بعد الإيقاف يظهر **النص كمسودة**، ولا يحفظ في حسابك إلا عند الموافقة، مع طابور محلي عند انقطاع الاتصال. «مسح التفريغ» يزيل النص واقتباسات المصدر ويحافظ على الملاحظات والقائمة. لا تشارك الواجهة الجديدة محتوى الجلسة مع المساعد النصي.

يحتاج التفريغ HTTPS وWorker وAudioWorklet وWebGPU يدعم shader-f16. تظهر رسالة قبل التنزيل إن لم يتوفر GPU المناسب؛ تبقى الملاحظات والقائمة متاحتين. يتوقف التسجيل عند إخفاء الصفحة أو الخروج منها، ويجب استئنافه صراحة. الإغلاق العادي يطلب اعتماد النص أو إلغاء المقطع؛ الإغلاق القسري أو إغلاق المتصفح قد يفقد الصوت والمسودة غير المعتمدين.

## الدقة والحدود

اختُبر محليًا على عينات عربية وفلسطينية وعبرية وإنجليزية. أفضل من Base الذي استُخدم سابقًا، لكنه يخطئ في أسماء الأشخاص واللهجات وخلط اللغات. لم تثبت دقة قريبة من الكمال أو أداء كل هاتف؛ يلزم تصحيح بعض الكلمات. على GPU NVIDIA المختبر استغرق تفريغ نحو عشر ثوان من الكلام قرابة 2–3.5 ثانية بعد التحميل؛ على Intel المختبر كان أبطأ، نحو 14–19 ثانية. اختيار GPU الفعلي يعتمد على المتصفح والنظام.

حدود الجلسة الحالية: 100 فقرة تفريغ، طول الفقرة 1000 محرف، 100 ملاحظة، 100 بند، 1000 عملية و180 ألف محرف للمحتوى. يجمع النص المتتابع في فقرات لتقليل استهلاك الحد. عند بلوغه يتوقف الحفظ برسالة ولا يحذف النص القديم. التصحيح يستخدم مقارنة النص الأصلي لحماية التعديل المتزامن. عزل الحسابات ومراجعات الحفظ والتزامن تبقى مطبقة.

## الاختبارات والتشغيل

استخدم Node 24 والـlockfile وJava 21 للمحاكيات:

```sh
ONNXRUNTIME_NODE_INSTALL=skip npm ci
npm run emulators
# طرفية ثانية
npm run dev:emulator
```

لا تحتاج هذه التعديلات ترحيل بيانات أو تغيير قواعد Firestore. تبقى الجلسات القديمة والملاحظات المقبولة متوافقة. انظر تقرير الجاهزية المؤرخ 2026-10-29 لتمييز اختبارات الواجهة المحقونة من الاستدلال الفعلي وحدود التحقق.

## تنزيل قابل للاستكمال

تُنزّل الأوزان في 35 جزءًا، لا يزيد الجزء على 16 ميبيبايت، مع فحص SHA-256 لكل جزء. تبقى الأجزاء المكتملة عند الانقطاع، ثم تجمع الملفات في OPFS ويعاد استخدامها. يطلب الموقع حفظ التخزين الدائم، لكن قرار الإخلاء النهائي للمتصفح.

في Chrome وEdge الداعمين لتنزيل الخلفية، تظهر رسالة تسمح بإغلاق تبويب WILO أثناء التنزيل. لا يلزم إبقاء نافذة الجلسة مفتوحة. لا يُضمن الاستمرار بعد إغلاق المتصفح بالكامل أو إيقاف الجهاز. إذا لم يدعم المتصفح ذلك، يظهر طلب واضح لإبقاء التبويب مفتوحًا؛ يواصل التنزيل عند إغلاق نافذة الجلسة داخل الموقع.

قد يحتاج التنزيل مساحة مؤقتة إضافية لتجميع الأجزاء. سرعة الإنترنت تحدد مدة نقل نحو 565 ميجابايت؛ التنزيل المتوازي والاستكمال لا يلغيان حجم الملفات. ملفات التشغيل الصغيرة قد تُجلب عند أول بدء. لا يلزم مفتاح API ولا توجد حصة لخدمة تفريغ سحابية؛ القدرة والسرعة تعتمدان على جهازك.

انظر [تقرير إصلاح التنزيل والعرض والحفظ](readiness/2026-10-29-session-download-recovery.md).

### تسجيل رسائل صوتية بدل التحليل المتواصل

يُسجّل المقطع كاملًا أولًا، دون كشف صمت أو عتبة شدة تحذف الكلام الهادئ، ودون طابور استدلال أثناء الحديث. يُغلق الميكروفون وتُرسل آخر العينات عند الإيقاف، ثم يبدأ التحويل المحلي. يبقى الصوت في الذاكرة لإعادة المحاولة عند فشل التحويل، ويُمحى عند نجاحه أو إلغائه. النص الناتج مسودة؛ لا يضاف إلا بموافقتك. عند إغلاق الجلسة يجب اعتماد المسودة أو إلغاؤها أولًا. إعادة تحميل الصفحة أو إغلاق المتصفح قسرًا قد يفقد التسجيل أو المسودة غير المعتمدين.

يبقى النموذج جاهزًا بين المقاطع داخل الجلسة، وتحرر موارده عند إغلاقها. لم يتغير النموذج ولا ملفاته، ولا يحتاج من ثبّته إلى تنزيل جديد. زمن معالجة المقطع يعتمد على الجهاز؛ هذا المسار يزيل التقطيع وتراكم المعالجة أثناء الكلام ولا يَعِد بتحويل فوري على كل GPU.
