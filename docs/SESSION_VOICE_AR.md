# مساعد الجلسة الصوتي — دليل التجربة

الميزة منشورة داخل جلسة العمل في الموقع. لا تحتاج مفتاح API أو خدمة تعرف صوتي سحابية.

## الاستخدام

1. افتح بطاقة، ثم **جلسة عمل**. الملاحظات والقائمة تخص هذه الجلسة وحدها، ولا تستبدلان قائمة البطاقة.
2. استخدم حقول **قائمة الجلسة** و**ملاحظات الجلسة** مباشرة، أو اختر لغة الكلام واضغط **بدء الاستماع**. الميكروفون لا يبدأ تلقائيًا.
3. في أول استخدام تُنزّل ملفات نموذج الصوت وبيئة التشغيل. يظهر التقدم، ويمكن الإلغاء. تُعالج المقاطع النهائية في Worker على جهازك.
4. قل أمرًا واحدًا واضحًا، مثل «ضيف فحص تسجيل الدخول للتشيك ليست». راجع التفريغ، صححه عند الحاجة، ثم اضغط **فهم هذا النص**.
5. راجع العملية والعنصر المقصود، واضغط **تطبيق الاقتراح**. التأكيد الصوتي الاختياري هو «نفّذ اقتراح 3» للرقم المعروض نفسه؛ «نعم» وحدها لا تنفذ شيئًا.
6. الحفظ المحلي والمزامنة المعلّقة يظهران بوضوح. بعد الاتصال، تتم المزامنة أثناء فتح التطبيق. عند التعارض تختار النسخة، ولا تُكتب فوق تعديل جهاز آخر تلقائيًا.
7. أوقف الاستماع أو أغلق الجلسة لتحرير الميكروفون والنموذج. لاسترجاع جلسة مكتملة افتح جلسة البطاقة، ثم سجل الجلسات، ثم **ملاحظات جلسة محفوظة**. زر **إظهار جلسات أقدم** يعرض دفعات إضافية ضمن آخر 500 جلسة يحتفظ بها سجل الحساب الحالي.

يمكن تعديل البنود وإكمالها وإعادة فتحها وحذفها يدويًا. يدعم الفهم المحلي أوامر جلسة محددة بالعربية والعبرية والإنجليزية، وليس مساعدًا عامًا مفتوح الصلاحيات. النفي والاحتمال والكلام المقتبس لا ينفذان عمليات. عند تشابه الأسماء تختار العنصر، والأوامر بالترتيب مثل «البند الثاني» ترتبط بمعرّفات ترتيب القائمة وقت الكلام.

## الملاحظات التلقائية والخصوصية

- **اقتراح ملاحظات تلقائيًا** يحوّل المقاطع المكتملة إلى مسودات مقتبسة من الكلام نفسه، مع تصنيف محلي بسيط للقرار أو المشكلة أو الخطوة القادمة. لا يؤلف ملخصات أو حقائق جديدة، ولا ينفذ عمليات من المسودات. تبقى عبارات الشك والنفي كما وردت.
- تُحفظ الملاحظة بعد قبولها فقط. المسودات غير المقبولة والتفريغ الجاري مؤقتان؛ أغلق الجلسة بعد مراجعتها إذا أردت الاحتفاظ بها.
- **حفظ التفريغ الكامل** خيار منفصل، مغلق افتراضيًا. تشغيله يسمح بحفظ المقاطع النهائية في حسابك. إغلاقه يحذف التفريغ واقتباسات المصدر المحفوظة، ويبقي الملاحظات المقبولة.
- الصوت لا يُسجّل في ملفات ولا يُرسل إلى مزود. التنزيلات الشبكية تخص ملفات النموذج والتشغيل فقط.
- مشاركة قائمة الجلسة ومقتطفات الملاحظات مع المساعد النصي السحابي اختيار مستقل، مغلق افتراضيًا. لا تشمل الصوت أو التفريغ الكامل. تطبيق أوامر الجلسة يمر بالتحقق والحفظ نفسيهما.
- يتضمن تصدير البيانات الشخصية محتوى الجلسات المتزامن. حذف الحساب يمحو المجموعة الفرعية على الخادم بالآلية الحالية، ويمسح مخزن الجلسات المحلي. التصدير من الخادم لا يتضمن تعديلات محلية لم تتزامن بعد.

## المتطلبات والحدود

يلزم HTTPS أو localhost، ومتصفح حديث يدعم Worker وWebAssembly وAudioWorklet وgetUserMedia. لا يعتمد المسار على SpeechRecognition الخاص بالمتصفح. يُوقف الاستماع عند إخفاء الصفحة أو مغادرتها أو تسجيل الخروج؛ استأنفه صراحة بعد العودة. عند فشل الإذن أو الجهاز أو النموذج يبقى الإدخال اليدوي متاحًا.

التخزين المؤقت يُعاد استخدامه بعد التنزيل، لكن المتصفح يستطيع إخلاءه أو رفض التخزين الدائم. يُطلب التخزين الدائم بأفضل جهد، وليس ضمانًا ضد حذف بيانات المتصفح. لا يُحمّل نموذج الصوت أثناء تثبيت PWA أو فتح الموقع العادي. يُمنع تشغيله بالتزامن مع WebLLM المحلي في التبويب، وعبر Web Locks بين التبويبات المدعومة.

دقة التعرف ليست مضمونة، خصوصًا اللهجة الفلسطينية، خلط اللغات والمصطلحات التقنية والضجيج. تصحيح التفريغ ومراجعة المقترح جزء من المسار. لا يُنفّذ نص جزئي، ولا يُخمّن بندًا عند الالتباس. حدود الجلسة: 100 بند، 100 ملاحظة، 100 مقطع تفريغ محفوظ، 1000 عملية، و180 ألف محرف للمحتوى؛ عند بلوغ الحد لا تُحذف البيانات القديمة بصمت. تُعرض 10 مسودات اقتراح كحد أقصى.

الملاحظات خاصة بصاحب الحساب، حتى إذا كانت البطاقة في مجموعة. السجل القديم والمؤقت وحفظ نقطة التوقف يبقيان متوافقين. هذه الميزة لا تصدّر صوتًا ولا تقرأ بريدًا ولا تنفذ أوامر على الحاسوب.

## تشغيل محلي وإعداد Firebase

استخدم Node 24 والـlockfile. لتجنب تنزيل CUDA غير المستخدم في المتصفح:

```sh
ONNXRUNTIME_NODE_INSTALL=skip npm ci
# الطرفية الأولى، مع Java 21:
npm run emulators
# الطرفية الثانية:
npm run dev:emulator
```

تستخدم الميزة `users/{uid}/sessionWorkspaces/{sessionId}`. تُلزم قواعد Firestore الملكية والحساب النشط، ومعرّفات البطاقة والجلسة، ووجود بطاقة المصدر عند الإنشاء، وعضوية المجموعة عند إنشاء جلسة مرتبطة بمجموعة، وزيادة مراجعة الحفظ. يتحقق العميل من المخطط الدلالي الكامل قبل الحفظ. لا يلزم فهرس Firestore جديد أو ترحيل للجلسات القديمة.

عند اعتماد النشر مستقبلًا يجب نشر القواعد أولًا ثم العميل وكتالوج أدوات Worker. التراجع عن العميل لا يتطلب حذف محتوى الجلسات أو تغيير وثائق `sessions` القديمة. لا تنشر القواعد أو العميل من هذا الدليل دون موافقة نشر مستقلة.

## إعادة الاختبار الصوتي

```sh
python3 scripts/download-session-speech-fixtures.py --model
# على Windows: ينشئ أمثلة صناعية فقط باستخدام أصوات النظام المثبتة
powershell -File scripts/generate-session-command-audio.ps1
npm run build
npm run preview -- --host 127.0.0.1 --port 5185
# في طرفية أخرى، بعد اكتمال الملفات:
SPEECH_TEST_ASSET_MIRROR=true npm run test:speech:audio
```

مرآة الاختبار تقدم ملفات النموذج العامة المثبتة نفسها من القرص إلى العامل الإنتاجي؛ لا تستبدل نتائج الاستدلال. تقرير الاختبار يسجل وسيلة النقل صراحة. تُعطل مسارات المرآة قبل اختبار التحميل دون اتصال. اترك المتغير مغلقًا لاختبار التنزيل العام الفعلي؛ سرعته وتوفره يعتمدان على الشبكة.

مصدر الأصوات البشرية [Google FLEURS](https://huggingface.co/datasets/google/fleurs) بترخيص CC-BY-4.0، مع الإسناد إلى Google. لا تُرفع الملفات الصوتية أو الأوزان إلى Git. أمثلة أصوات Windows صناعية، والضجيج مضاف حسابيًا بنسبة 20dB، والمثال المختلط تركيب صناعي وليس تسجيلًا طبيعيًا للهجة فلسطينية.

لاختبار المسار الكامل بالصوت على محاكيات Firebase، بعد توليد ملف الأمر الإنجليزي والأوزان:

```sh
SPEECH_TEST_REAL_MIC_FILE=.wrangler/session-voice-audio/command-en.wav node scripts/run-browser-tests.mjs tests/browser/sessionVoiceRealAudio.spec.ts
```

يعيد Chromium تشغيل WAV قانوني عبر جهاز ميكروفون افتراضي، ويستخدم Worker الحقيقي، ثم يراجع الأمر ويحفظه ويعيد تحميله. هذا ليس اختبار ميكروفون مادي. تحقق عمليًا من جهاز Android ومتصفح iOS ودقة اللهجة الفلسطينية قبل اعتماد الصوت دون مراجعة، وجرّب رفض الإذن، فصل الميكروفون، الخلفية، وضع عدم الاتصال، والتراجع بعد تعديل آخر.
