# Admin pinboard review — 2026-11-04

## Latest scope

The user clarified that the working site must not be abruptly replaced: retain its current colors, typography, navigation and capabilities; focus on button placement, motion, lighter menus, and a central pinned-note board with investigation-board-like strings and markings. This supersedes the earlier request for a wholesale dashboard replacement.

The unshipped Shadcn Admin/sidebar/font draft was moved into ignored `.wrangler/design-sources/unused-studio`. No new sidebar, dashboard shell, font or Radix dependency is shipped. The existing account-owned AI binding and URL cleanup are untouched. Visual changes remain gated by the existing verified-admin predicate. The historical internal `kitchenStudy` context/attribute name remains for compatibility; it does not indicate use of dqnamo component source.

## Implemented

- Central paper-note board, small red pins, paper shadows and restrained variations of the existing cream/green colors. Current font and user theme/background controls are retained.
- Current collapsed-card workflow, original editors/actions, notes, drag handles, sorting engine and persistence callbacks are retained. Expanded cards still span the board. No card migration or new storage model.
- Replaced the rejected admin CSS layer rather than stacking another full-screen theme over it. Removed its unused per-pointer coordinate tracking.
- Rough Notation 0.5.1 (MIT) draws real animated underlines on hover/focus and red circles on dates classified as overdue by the existing `matchesView` policy. The library is bundled locally, without CDN calls. Its license is deployed at `/licenses/rough-notation-MIT.txt`.
- Annotation wrappers contain the library-generated SVG and remove it on cleanup. Decoration is aria-hidden/non-focusable and respects reduced motion. Markings are contextual decoration, not user-authored saved drawings.
- Optional section strings connect cards sharing an actual existing section. They are not arbitrary connections or task dependencies. Cards without valid section membership are excluded. The toggle is disabled when fewer than two visible cards share an existing section, and an Info disclosure explains the meaning.
- Strings are hidden during dragging and remeasured after sorting, resizing or card expansion. They do not intercept input. No fake graph, new dependency relation, cloud write or additional AI request is introduced.
- Compact labels and existing full sync-detail disclosure are retained. The repeated visible drag instruction is hidden for the admin board; accessible DnD instructions, labels and live announcements remain.
- Menu treatment is limited to rounding, shadows, and entry/press motion; working routes and locations remain recognizable. No notices about errors, consent, permissions or conflicts were blanket-hidden.

Section strings and contextual markings are recomputed from current records and do not require new persisted data. Other users continue to see their current public design.
