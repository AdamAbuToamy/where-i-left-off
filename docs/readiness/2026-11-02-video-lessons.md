# تطبيق دروس الفيديوهات — 2026-11-02

READY للتغييرات المحددة أدناه. هذا ليس اعتماد جاهزية المنتج كله أو Google Play. النشر على Hosting، والتغيير المرئي الجديد محصور في تصميم الإدارة الاختياري. تحسينات التحميل والكاش وتصحيح إفصاح الخصوصية مشتركة ولا تغيّر صلاحيات الحساب أو مخطط بياناته.

## ما راجعته وطبقته

راجعت لقطات موزعة على الفيديوهات الخمسة، وفصّلت فيديو الأداء على فواصل 2.85 ثانية. الفيديوهات أمثلة تعليمية وليست تعليمات موثوقة لتنزيل حزم أو تغيير البنية دون فحص. قُرئ AGENTS.md ودليل الهندسة. الملف docs/knowledge/university/university_rules.md غير موجود؛ لم أدّع قراءته.

| الفيديو | التطبيق في WILO |
|---|---|
| ثلاثة اختيارات بدل قائمة | اختيار العربية/العبرية/الإنجليزية مباشرة في تصميم الإدارة، مع حالة محددة وانتقال قصير ودعم لوحة المفاتيح وتقليل الحركة. الواجهة الأصلية باقية لغير المشاركين. |
| كلفة AI وسياق المحادثة | تشخيص totalTokens رقمي من رد المزود، مع اختبار يمنع نسخ الرسائل أو بيانات المزود إلى التشخيص. لا تغيير للمودل ولا اقتطاع عشوائي للسياق. حدود الطلب والمهلة والبث موجودة بالفعل. |
| أداء المواقع | تحميل الصفحات عند فتحها، توحيد طلب إعداد الإضافة المتزامن بمهلة 5 ثوانٍ ودون كاش دائم، كاش طويل للملفات ذات البصمة، إعادة تحقق HTML وSW، وإصلاح اسم كاش التطبيق ليتغير مع محتواه. |
| جاهزية Google Play | صححت وصف مساعد AI في الخصوصية الإنجليزية والعربية والعبرية ليتوافق مع Pollinations ومفتاح كل مستخدم وPDF. الدخول والتصدير وحذف الحساب الموجود لم يُحذف أو يُضعف. مراجعة Play Console ونسخة Android الحقيقية لم تُنفذ. |
| جودة التصميم وأدوات التحقق | استُخدمت مكتبات المشروع وقياسات الحزمة واختبارات المتصفح الفعلية. أصلحت خروج قائمة الأدوات عن شاشة الهاتف عند تغيّر ارتفاع المحتوى بإعادة حساب الموضع. لا تثبيت لحزم مهارات عشوائية من الفيديو. |

## مصفوفة توصيات فيديو الأداء

| التوصية | القرار والدليل أو الحد |
|---|---|
| Skeleton | شاشة التحميل المخصصة الحالية محفوظة ومستخدمة في حدود تحميل الصفحات. لم أدّع إضافة skeleton لكل صفحة. |
| WebP | لم تُحوّل الأيقونات ورسوم الواجهة إلى صور؛ لا مكتبة صور فوتوغرافية في النطاق المتأثر. |
| منع الطلبات المكررة | loadExtensionConfig يشارك الطلب الجاري فقط؛ اختبارات التزامن والتحقق والفشل والمهلة نجحت. |
| Debounce | البحث في مساحة العمل محلي؛ لم أضف تأخيرًا مصطنعًا لكل ضغطة أو ادّع تدقيق كل بحث. |
| CDN | بقي Firebase Hosting/CDN، دون استضافة إضافية. |
| مهام الخلفية | مسارات التصدير الحالية محفوظة. لم أضف طابور خادم أو أعدّل معالجة PDF دون قياس يبرره. |
| N+1 | لا تغيير شامل للاستعلامات أو ادّع عدم وجودها في كل المشروع؛ مستمعات البيانات وحدود الحساب باقية. |
| ضغط النقل | فحص رؤوس الأصول المنشورة موثق منفصلًا؛ لا ادعاء ضغط من حجم gzip محلي وحده. |
| Redis | غير مضاف؛ Firebase هو مخزن البيانات الحالي، وليس لدينا سبب مقاس لإضافة مخزن آخر. |
| إزالة الاعتمادات | لا تغيير تبعيات أو lockfile؛ التحميل المؤجل يُعالج الكود غير المطلوب الآن دون حذف ميزات. |
| Streaming | بث المساعد الحالي محفوظ؛ لا تنفيذ لأجزاء tool arguments قبل اكتمال التحقق. |
| تحديث الواجهة فورًا | طوابير التعديلات الحالية ومعاملات الحفظ محفوظة؛ لم ألغ فحوص النسخ والتزامن. |
| Lazy images | لا تغيير خارج الصور المتأثرة؛ لا إضافة صور كبيرة جديدة. |
| طلبات مستقلة بالتوازي | بقيت عمليات القراءة المستقلة الموجودة؛ لا موازاة لكتابات تعتمد على بعضها. |
| فهارس قاعدة البيانات | لم تُغيّر دون استعلام مقاس يبررها. قواعد الصلاحيات اختُبرت. |
| تتبع البطء | تشخيص التوقيت الموجود أضيف له عدد التوكنات فقط؛ لا رسائل أو مفاتيح في القياس. |
| قرب الخادم من DB | لا نقل قواعد بيانات أو موارد إنتاج في هذا التكليف. |
| SSR/التوليد المسبق | لا تحويل تطبيق Firebase المصادق إلى إطار آخر. صفحات التعريف العامة الحالية باقية. |
| تأجيل الطرف الثالث | المساعد وPDF ومساراته الحالية مؤجلة؛ لم أزل App Check أو أضعف الدخول لأجل الأداء. |
| Timeouts | مهلة جديدة لقراءة إعداد الإضافة، وحدود المساعد الحالية محفوظة. |
| تقسيم JS حسب الصفحة | مطبق في AccountPage؛ اختبار المتصفح وفحص static-import graph يتحققان منه. |
| أعمدة الاستعلام | Firestore SDK مختلف عن مثال SQL؛ لا إسقاط حقول ضرورية بصمت. |
| Connection pooling | يديره SDK والخدمات الحالية؛ لم أضف pooling SQL غير مناسب. |
| منع الرندر غير اللازم | لا memo شامل دون قياس؛ الإصلاحات محصورة في التحميل وإعادة موضع القائمة. |
| Browser cache | رؤوس immutable للأصول ذات البصمة، no-cache لـHTML وSW، وإصلاح إصدار الكاش. |
| Load balancing | لا إضافة خادم أو load balancer؛ الاستضافة المدارة الحالية باقية. |
| Self-host fonts | خطوط النظام الحالية محفوظة، ولا تحميل خدمة خطوط جديدة. |
| Real-user metrics | لم أضف تتبع مستخدمين أو أرسل بيانات جديدة لخدمة تحليلات؛ القياس محلي. |
| اختبارات الأداء | فحص حزم الإنتاج ورحلة المتصفح وفتح PWA دون اتصال. لا ادعاء قياس هواتف حقيقية أو شبكات 3G. |

- npm test: نجح 1234 اختبارًا في 111 ملفًا قبل إضافة اختبار التوكنات واختبار SW. بعد إضافتهما نجح فحص المساعد والبث (20 اختبارًا) وفحص مولّد SW (اختبار واحد). هذه أعداد تشغيلات موثقة، لا مجموع اختبارات فريدة مزعوم.
- node --test push-worker/*.test.mjs: نجح 874 اختبارًا.
- npm run test:rules: نجح 680 اختبارًا على Firestore emulator/Java 21.
- npm run test:auth:recovery: نجحت الاختبارات الثلاثة على Auth emulator.
- رحلات Chromium السبع: الهاتف وسطح المكتب، hover، سحب البطاقات واستمرار ترتيبها، التنقل بين الصفحات، التبديل التلقائي، اللغة ولوحة المفاتيح، الرجوع للأصل؛ كلها نجحت. فشل أولي في موضع قائمة الهاتف كُشف وأُصلح قبل إعادة المجموعة.
- check:architecture: نجح، 22 وحدة دون مخالفات.
- lint: صفر أخطاء وتحذير سابق واحد في AssistantWidget. TypeScript وproduction build وفحص أنماط الاعتمادات السرية نجحت.
- scripts/check-route-bundles.mjs: يتحقق أن صفحات الإدارة والإعدادات والتحليلات والمكتبة والجامعة والإشعارات ليست ضمن static startup graph. دليل الأحجام في ملف bundle JSON المجاور. حزمة الدخول وحدها انخفضت من 1,347,867 إلى 553,986 بايت؛ هذه ليست نسبة لتحسن السرعة أو إجمالي التنزيل.
- اختبار PWA محلي ببناء الإنتاج مع منع الاتصالات الخارجية: كاش بإصدار محتوى، 70 ملفًا، وجود صفحة الإعدادات في الكاش، وإعادة تحميل دون اتصال. ما زالت الصفحات تُخزّن للعمل دون اتصال بعد تحميل التطبيق؛ لم نلغ هذه القدرة لتحقيق رقم شكلي.
- تسجيلات الاختبارات في .wrangler/video-*.log. لم تُنفذ كتابة لحساب إنتاج، ولا تعديل Auth domains أو Firestore rules أو worker deployment.
